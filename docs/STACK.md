## 8. UI/UX 방법론

| 방법 | 이 프로젝트에서 쓰는 방식 |
|---|---|
| 사용자 여정 설계 | 지도, 가게 입장, 이번 달 사건, 운영 계획, 한 달 재생, 정산, 다음 달 |
| 정보가 보이는 3D | 메뉴판 가격, 대기 줄, 고기와 소주병, 날씨, 경쟁점이 숫자를 그대로 보여줌 |
| 점진적 공개 | 처음엔 핵심 지표만, 근거와 가정은 눌러야 펼쳐짐 |
| 튜토리얼 3단계 | 처음 하는 사람도 혼자 플레이 가능하게 |
| 신뢰 표시 | 모든 숫자에 출처 또는 가정 표시, 사람 검토 수, 운의 범위(p10~p90) |
| 플레이 테스트 | 직접 해보고 지루한 지점, 헷갈리는 지점 기록 |
| 접근성 점검 | 대비, 글자 크기, 키보드 조작 (다음 단계) |
